# W3: six current fixed head feeds

One matched native Foundation and UpperCarrier set replaces two prior prints.
The qualified W2 YawCarrier stays unchanged, with no extra jaw on its staggered
sleeves/taper. All other current M2/W2/W4 parts stay selected. The native
return channels and independent intact-insulation grips are not adhesive
wire restraints. G_AUX uses one reused SJ4570 case-retention pair only.

Eight independent insulation grips and four case bands use twelve new T18I.
Case bands have both return and side channels through their native floors;
PCB heads face upward. Sketches use body-local coordinates, not root-only
offsets. The saved corrected native graph is reused, never rebuilt in place.

The six feeds end on current W2 boundaries, without an extra joint there.
Both real opposite FHAC exits, two individually insulated factory splices,
two known PCB formed ends and all independent grips are accounted for.
Full upstream source inputs and three other G_AUX ports remain W5/W1.

This is an open prototype. Functional neck electronics and the red return
sit outside the omitted cosmetic torso; the latter reaches Z160.594 mm.
Accepted torso dimensions and side width are unchanged. Replacement prints
retain a 10 mm allowance within 256 mm per axis, but are not print-ready.

Read selection.json for current quantities, continuous wire fit allowances,
assembly, ATO service and delivered-fit gates. W2 local wire procurement is
replaced by these aggregate contributions, not added again. Global stock,
electrical/load approval, printing and physical tests remain open.

No purchase, energizing or physical PASS is authorized by this package.

Provenance: historical hash-pinned input files remain in their original local
folders. This own-only milestone does not stage unrelated historical untracked
inputs or user changes. The relocated FCStd is self-contained; a clean-clone
rebuild of every historical proof is not claimed by this local checkpoint.

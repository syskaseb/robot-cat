# Tożsamość i rewizje części

[aux-pilot.json](aux-pilot.json) nadaje numery czterem podporom i wiąże je
z dokumentami/obiektami FreeCAD. To częściowy BOM pilotażu, nie lista zakupowa
całego kota. Płyta ramy, mostek i skorupa są częściami współpracującymi, a nie
dodatkowymi sztukami do ponownego zakupu/druku.

`RC-*` oznacza projektowane części; `BUY-*` rozpoznaną część handlową;
`REF-*` nominalną referencję bez nowego zatwierdzenia produktu. Rewizja A
identyfikuje geometrię, nie jest statusem gotowości do druku.

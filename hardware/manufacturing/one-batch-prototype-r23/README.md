# R23: oba końce pętli yaw

Dwa zamienne STL,66 zadań/100PETG/4próbki. Zachowane uszy/P0 i fabryczny kabel250mm. Nowa pętla260mm ma zgodne styczne, minimalny próbkowany R32,948mm; obie integralne podpory i sztywna kieszeń lutów.44 T18I z istniejącego bag100. Maksymalny Y240,30mm: duża zewnętrzna pętla prototypu, ocenić zaczepianie po złożeniu. Złącze rozpiąć i opaski przeciąć przed zdjęciem osłony. Nadal otwarte centralne feedy, stały yaw i pozostałe SKU/zabezpieczenia. Slicer/druk/realne pasowania w fazie2, ROS w fazie3.
